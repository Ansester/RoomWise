## Attribution in portfolios

Use **co-developed** or **collaborative project** when describing RoomWise. A personal portfolio can identify a contributor's specific work once that contributor has confirmed it. Avoid presenting the entire project as a solo build or treating the public snapshot's author field as proof of sole authorship.

Project descriptions should also preserve the [claim boundaries](CLAIMS.md): implemented software and automated checks are established; user impact, production operation, and live-provider reliability have not been established by those checks.

No project licence is created by this contributor record. Check the repository root for a licence and contact the contributors about reuse permissions if none is supplied.
